# 게임 기획서

- 게임명: 미정
- 작성자: 전승효
- 장르: 2D 탑다운 액션

## 게임 소개

한 방에 적을 쓰러뜨리는 원샷원킬 액션 게임이다. 핫라인 마이애미처럼 위에서 내려다보는 시점에서 빠르게 움직이며 싸운다.

## 진행 방식

플레이어와 적 모두 공격을 한 번 맞으면 쓰러진다. 적의 공격을 피하며 방 안의 적을 모두 처치하면 클리어한다. 처음에는 방 하나로 구성하고, 실패하면 같은 방에서 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 공격 |
| R | 재시작 |
