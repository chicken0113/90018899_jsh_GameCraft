# 미정 게임 기획서
- 게임: 미정
- 작성자: 전승효

## 개요
- 장르: 2D 탑다운 액션
- 게임 소개
  - 플레이어와 적 모두 공격 한 번에 사망하는 원샷원킬 액션 게임
  - 재미 요소
    - 한 번의 실수로 사망하는 긴장감
    - 반복 도전을 통해 적의 배치와 공격을 파악하는 재미
    - 빠르게 적들을 처치하고 스테이지를 클리어하는 쾌감

## 게임 진행
- 스테이지에 배치된 모든 적을 처치하면 클리어한다.
- 플레이어가 공격받으면 즉시 사망한다.
- 사망하면 스테이지를 처음부터 다시 시작한다.

## 조작
- WASD: 이동
- 마우스: 조준
- 마우스 왼쪽 버튼: 공격
- R: 재시작

## 플레이 Stage
- 하나의 방에 플레이어와 적들이 배치된다.
- 모든 적을 처치하면 스테이지가 끝난다.
