# Shooter Lounge 게임 기획서

- 작성자: 전승효
- 장르: 2D 탑다운 액션
- 게임 이름: Shooter Lounge

## 게임 소개

문과 복도로 연결된 방을 돌아다니며 적을 처치하는 원샷원킬 액션 게임이다. 플레이어와 적 모두 총알을 한 발 맞으면 쓰러진다. 핫라인 마이애미처럼 빠르게 움직이고, 실패하면 적의 위치를 기억해 다시 도전하는 재미를 목표로 한다.

## 게임 목표와 진행

1. 시작 화면에서 게임을 시작한다.
2. 지하철역, 아파트, 여러 방으로 이어진 건물 순서로 적을 처치한다.
3. 해당 스테이지의 적을 모두 쓰러뜨리면 클리어 문구가 뜬다. 시작 지점으로 돌아오면 Enter로 다음 스테이지를 시작할 수 있다.
4. 세 스테이지를 모두 마치면 별도의 게임 클리어 화면이 나온다. 사망하면 R로 현재 스테이지를 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| Enter 또는 시작 버튼 클릭 | 시작 화면에서 게임 시작 |
| R | 현재 스테이지 재시작. 게임 클리어 화면에서는 시작 화면으로 이동 |
| Enter | 클리어 후 다음 스테이지로 이동 |

## 전투 규칙

- 잠기지 않은 문에 몸을 밀면 진행 방향으로 열린다. 총알은 문짝에 맞으면 막히고, 플레이어가 밀어 연 문짝에 적이 맞으면 잠시 행동을 멈춘다. 열린 문은 잠시 뒤 닫힌다.
- 순찰병과 경비견은 정해진 지점을 왕복한다. 플레이어를 발견하면 추격하고, 놓치면 지나온 길을 되짚어 순찰을 재개한다.
- 플레이어와 적은 총알 한 발에 쓰러진다.
- 적의 발견 거리는 짧게 설정했다. 공격 전에 머리 위에 `!`가 표시되고, 총을 든 적은 0.9초 동안 조준한 뒤 발사한다. 근접 적도 잠시 공격 자세를 취하므로 피할 시간이 있다.
- 총을 든 적의 발사 간격은 무기에 따라 1.5~1.9초다. 근접 무기를 든 적, 개, 덩치 큰 적은 접근해 공격한다.
- 화면 위쪽에 현재 구역, 남은 적 수와 조작 방법을 표시한다.

## 스테이지 구성

핫라인 마이애미의 지하철역, 아파트, 다층 건물 방 배치와 적의 시작 위치를 바탕으로 스테이지를 구성했다. 가구·식물·기계 같은 장식물은 모든 스테이지에서 제거하고 바닥, 벽, 문과 이동 경로를 남겼다. 게임 화면에는 스테이지 이름이나 번호를 표시하지 않는다.

| 진행 구역 | 적 수 |
| --- | ---: |
| 지하철역 두 구역 | 9 |
| 아파트 입구와 2층 | 6 |
| 여러 방으로 이어진 건물 | 59 |

첫 두 스테이지는 원본 방 데이터의 벽, 문, 계단과 적 배치를 옮겼다. 현재 구역의 적을 정리하면 다음 구역으로 이동할 수 있다. 마지막 스테이지는 기존 네 구역을 사용하며, 다른 구역을 거쳐 돌아와도 처치 상태가 유지된다.

## 화면과 소리

원본 방의 바닥과 벽을 어둡게 조정해 배경으로 사용한다. 플레이어와 적은 기존 게임 스프라이트를 사용한다. 시작 화면, 적 전원 처치 문구, 마지막 게임 클리어 화면을 표시한다. 배경음과 발사·피격·클리어 효과음은 낮은 볼륨으로 재생한다.
