# 미정 게임 기획서
- 게임: 미정
- 작성자: 전승효

## 개요
- 장르: 2D 탑다운 액션
- 게임 소개
  - 플레이어와 적 모두 공격 한 번에 사망하는 원샷원킬 액션 게임
  - 재미 요소
    - 한 번의 실수로 사망하는 긴장감
    - 반복 도전을 통해 적의 배치와 공격을 파악하는 재미
    - 빠르게 적들을 처치하고 스테이지를 클리어하는 쾌감

## 게임 진행
- 문과 복도로 연결된 방들을 돌아다니며 적과 싸운다.
- 스테이지의 모든 적을 처치하면 클리어한다.
- 플레이어가 공격받으면 즉시 사망한다.
- 사망하면 스테이지를 처음부터 다시 시작한다.

## 조작
- WASD: 이동
- 마우스: 조준
- 마우스 왼쪽 버튼: 공격
- R: 재시작

## 플레이 Stage
- 여러 방이 문과 복도로 이어진 실내 스테이지다.
- 방마다 적과 가구의 배치를 다르게 한다.

## 전투와 클리어
- 마우스로 방향을 조준하고 클릭으로 공격한다.
- 플레이어와 적은 공격을 한 번 맞으면 쓰러진다.
- 방을 이동하며 스테이지의 적을 모두 처치하면 클리어한다.
- 사망하거나 R을 누르면 시작 위치에서 다시 시작한다.

## 3차 구현 내용
- 연결된 세 방을 배경으로 표시하고 플레이어 캐릭터를 화면에 그린다.
- WASD로 이동하며 열린 문과 통로를 지나 다른 방으로 갈 수 있다.
- 배경음악을 반복 재생한다.
- 적, 조준, 공격, 클리어 처리는 이후에 구현한다.
