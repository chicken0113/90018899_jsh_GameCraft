# 미정 게임 기획서

- 작성자: 전승효
- 장르: 2D 탑다운 액션
- 게임 이름: 미정

## 게임 소개

문과 복도로 연결된 방을 돌아다니며 적을 처치하는 원샷원킬 액션 게임이다. 플레이어와 적 모두 총알을 한 발 맞으면 쓰러진다. 핫라인 마이애미처럼 빠르게 움직이고, 실패하면 적의 위치를 기억해 다시 도전하는 재미를 목표로 한다.

## 게임 목표와 진행

1. 적이 없는 시작 방에서 출발한다.
2. 문과 복도를 지나 다른 방으로 이동하며 적과 싸운다.
3. 스테이지의 적을 모두 처치하면 클리어한다.
4. 플레이어가 총알에 맞으면 게임이 멈추고, R을 누르면 처음부터 다시 시작한다.

한 판은 적이 없는 입구에서 출발해 중앙 공간과 세 방향의 방을 돌아다니며 적 여덟 명을 모두 쓰러뜨리는 구성이다. 화면 위쪽에 남은 적 수를 표시해 진행 상황을 확인할 수 있다. 사망하거나 클리어한 뒤에는 R로 같은 스테이지를 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| R | 스테이지 재시작 |

## 전투 규칙

- 총알은 벽을 통과하지 못한다.
- 플레이어와 적은 총알 한 발에 사망한다.
- 적은 플레이어가 보이면 가까이 다가와 총을 쏜다.
- 플레이어는 이동할 때 이동 방향을 바라보고, 발사할 때는 마우스 쪽을 바라본다.
- 화면에는 남은 적의 수와 조작 방법을 표시한다.

## 스테이지 구성

현재 스테이지는 아래쪽 입구, 중앙 공간, 왼쪽·오른쪽·위쪽 방으로 구성했다. [핫라인 마이애미의 Hot & Heavy](https://hotlinemiami.fandom.com/wiki/Hot_%26_Heavy)처럼 입구에서 여러 방향으로 갈라지는 진행을 참고했다. 입구에는 적이 없고 중앙과 세 방에 두 명씩 배치했다. 열린 문을 통해 방 사이를 이동하며, 벽과 엄폐물은 이동과 총알을 막는다. 화면은 플레이어를 따라간다.

바닥·벽·문 타일을 게임에서 직접 배치한다. 방마다 바닥색을 다르게 하고 안쪽에 엄폐물을 놓아 이동 경로와 공격 각도를 바꿨다. 이전에 만든 `stage01.png`는 초기 스테이지 시안으로 보관한다.

## 적 구성

적 이미지는 빨강, 청록, 노랑, 보라 네 종류를 준비했다. 현재는 외형과 발사 간격만 다르고 모두 총알 한 발씩 공격한다. 이후에는 무기 종류에 맞게 연사나 산탄 같은 공격 방식도 구분할 계획이다.

## 화면과 소리

어두운 실내에 분홍색과 청록색 네온을 사용한다. 플레이어에게는 걷기 동작과 방향 전환을 넣고, 총알이 부딪히거나 캐릭터가 맞을 때 효과를 표시한다. 배경음악과 발사·피격·클리어 효과음은 준비되어 있지만, 현재 작업 중에는 소리를 꺼 두었다. 최종 제출 전에 다시 켤 예정이다.

## 현재 구현과 남은 작업

배경 표시, 캐릭터 이동, 방 이동, 마우스 발사, 적의 추적과 공격, 사망·재시작, 클리어까지 구현했다. 현재 한 스테이지를 처음부터 끝까지 플레이할 수 있다. 앞으로는 소품 종류를 늘리고 적의 움직임과 전투 연출을 다듬을 예정이다.
