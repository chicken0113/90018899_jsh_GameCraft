# 미정 게임 기획서

- 작성자: 전승효
- 장르: 2D 탑다운 액션
- 게임 이름: 미정

## 게임 소개

문과 복도로 연결된 방을 돌아다니며 적을 처치하는 원샷원킬 액션 게임이다. 플레이어와 적 모두 총알을 한 발 맞으면 쓰러진다. 핫라인 마이애미처럼 빠르게 움직이고, 실패하면 적의 위치를 기억해 다시 도전하는 재미를 목표로 한다.

## 게임 목표와 진행

1. 적이 없는 시작 방에서 출발한다.
2. 문과 복도를 지나 다른 방으로 이동하며 적과 싸운다.
3. 스테이지의 적을 모두 처치하면 클리어한다.
4. 플레이어가 총알에 맞으면 게임이 멈추고, R을 누르면 처음부터 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| R | 스테이지 재시작 |

## 전투 규칙

- 총알은 벽을 통과하지 못한다.
- 플레이어와 적은 총알 한 발에 사망한다.
- 적은 플레이어가 보이면 가까이 다가와 총을 쏜다.
- 플레이어는 이동할 때 이동 방향을 바라보고, 발사할 때는 마우스 쪽을 바라본다.
- 화면에는 남은 적의 수와 조작 방법을 표시한다.

## 스테이지 구성

현재 스테이지는 연결된 방 세 개로 구성했다. 첫 방에는 적이 없고, 두 번째 방에 적 세 명, 세 번째 방에 적 두 명이 있다. 열린 문을 통해 방 사이를 이동할 수 있으며, 벽에는 이동과 총알이 막힌다. 방을 이동하면 화면이 플레이어를 따라간다.

바닥·벽·문 타일과 소품 이미지는 따로 준비했다. 현재 스테이지 배경은 이 타일을 배치해 만든 한 장의 이미지다. 이후에는 방마다 가구와 적의 배치를 더 다르게 만들 계획이다.

## 적 구성

적 이미지는 빨강, 청록, 노랑, 보라 네 종류를 준비했다. 현재는 외형과 발사 간격만 다르고 모두 총알 한 발씩 공격한다. 이후에는 무기 종류에 맞게 연사나 산탄 같은 공격 방식도 구분할 계획이다.

## 화면과 소리

어두운 실내에 분홍색과 청록색 네온을 사용한다. 플레이어에게는 걷기 동작과 방향 전환을 넣고, 총알이 부딪히거나 캐릭터가 맞을 때 효과를 표시한다. 배경음악은 계속 재생하며 발사, 피격, 클리어에는 각각 효과음을 사용한다.

## 현재 구현과 남은 작업

배경 표시, 캐릭터 이동, 방 이동, 마우스 발사, 적의 추적과 공격, 사망·재시작, 클리어까지 구현했다. 앞으로는 방 안에 소품을 배치하고 적의 움직임과 전투 연출을 다듬을 예정이다.
