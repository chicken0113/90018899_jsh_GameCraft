# 미정 게임 기획서

- 작성자: 전승효
- 장르: 2D 탑다운 액션
- 게임 이름: 미정

## 게임 소개

문과 복도로 연결된 방을 돌아다니며 적을 처치하는 원샷원킬 액션 게임이다. 플레이어와 적 모두 총알을 한 발 맞으면 쓰러진다. 핫라인 마이애미처럼 빠르게 움직이고, 실패하면 적의 위치를 기억해 다시 도전하는 재미를 목표로 한다.

## 게임 목표와 진행

1. 1층 남쪽 출입구 앞에서 시작한다.
2. 1층의 적을 모두 처치한 뒤 북서·동쪽·남동 계단으로 이동한다.
3. 2층의 세 구역을 모두 정리하고 차로 돌아오면 클리어한다.
4. 사망하거나 클리어한 뒤 R을 누르면 처음부터 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| R | 스테이지 재시작 |

## 전투 규칙

- 잠기지 않은 문에 몸을 밀면 진행 방향으로 열린다. 총알은 문짝에 맞으면 막히고, 플레이어가 밀어 연 문짝에 적이 맞으면 잠시 행동을 멈춘다. 열린 문은 잠시 뒤 닫힌다.
- 순찰병과 경비견 15마리는 정해진 지점을 왕복한다. 플레이어를 발견하면 추격하고, 놓치면 지나온 길을 되짚어 순찰을 재개한다.
- 플레이어와 적은 총알 한 발에 쓰러진다.
- 총을 든 적은 플레이어가 보이면 사격한다. 근접 무기를 든 적, 개, 덩치 큰 적은 접근해 공격한다.
- 화면 위쪽에 현재 구역, 남은 적 수와 조작 방법을 표시한다.

## 스테이지 구성

핫라인 마이애미의 10장 ‘Hot & Heavy’ 방 데이터를 바탕으로 1층과 2층의 북서·동쪽·남동 구역을 옮겼다. 원본 데이터에서 벽, 바닥, 문, 계단, 소품과 적의 시작 좌표를 가져왔다. 적은 1층 13명, 2층 북서 17명, 동쪽 14명, 남동 15명이다.

현재 구역의 적을 정리하면 계단을 이용할 수 있다. 다른 구역을 거쳐 돌아와도 처치 상태는 유지된다. 조작과 재시작은 과제의 방식을 따른다. 순찰 경로는 원작의 시작 위치를 기준으로 이 스테이지에 맞춰 지정했다.

## 화면과 소리

배경과 스프라이트는 GameCraft의 분홍·청록 네온 리소스로 구성했다. 계단, 수조, 차량과 개는 같은 팔레트에 맞춰 그렸다. 배경음과 발사·피격·클리어 효과음을 재생하며, 전체 소리는 낮은 볼륨으로 설정했다.
