# 미정 게임 기획서

- 작성자: 전승효
- 장르: 2D 탑다운 액션
- 게임 이름: 미정

## 게임 소개

문과 복도로 연결된 방을 돌아다니며 적을 처치하는 원샷원킬 액션 게임이다. 플레이어와 적 모두 총알을 한 발 맞으면 쓰러진다. 핫라인 마이애미처럼 빠르게 움직이고, 실패하면 적의 위치를 기억해 다시 도전하는 재미를 목표로 한다.

## 게임 목표와 진행

1. 1층 남쪽 출입구 앞에서 시작한다.
2. 적을 처치하고 열린 계단으로 이동해 해당 스테이지의 구역을 정리한다.
3. 앞의 두 스테이지는 남쪽 출구로, 마지막 스테이지는 입구의 차로 돌아오면 끝난다. Enter를 눌러 다음 스테이지로 간다.
4. 세 스테이지를 모두 마치면 게임이 끝난다. 사망하면 R로 현재 스테이지를 다시 시작한다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 버튼 | 발사 |
| R | 현재 스테이지 재시작. 게임을 끝낸 뒤에는 처음부터 시작 |
| Enter | 클리어 후 다음 스테이지로 이동 |

## 전투 규칙

- 잠기지 않은 문에 몸을 밀면 진행 방향으로 열린다. 총알은 문짝에 맞으면 막히고, 플레이어가 밀어 연 문짝에 적이 맞으면 잠시 행동을 멈춘다. 열린 문은 잠시 뒤 닫힌다.
- 순찰병과 경비견은 정해진 지점을 왕복한다. 플레이어를 발견하면 추격하고, 놓치면 지나온 길을 되짚어 순찰을 재개한다.
- 플레이어와 적은 총알 한 발에 쓰러진다.
- 적의 발견 거리는 짧게 설정했다. 공격 전에 머리 위에 `!`가 표시되고, 총을 든 적은 0.9초 동안 조준한 뒤 발사한다. 근접 적도 잠시 공격 자세를 취하므로 피할 시간이 있다.
- 총을 든 적의 발사 간격은 무기에 따라 1.5~1.9초다. 근접 무기를 든 적, 개, 덩치 큰 적은 접근해 공격한다.
- 화면 위쪽에 현재 구역, 남은 적 수와 조작 방법을 표시한다.

## 스테이지 구성

핫라인 마이애미의 10장 ‘Hot & Heavy’ 방 데이터를 바탕으로 1층과 2층의 북서·동쪽·남동 구역을 옮겼다. 원본 데이터에서 벽, 바닥, 문, 계단, 소품과 적의 시작 좌표를 가져왔다. 기존 전체 구역은 마지막 스테이지에서 사용한다.

| 스테이지 | 진행 구역 | 적 수 |
| --- | --- | ---: |
| 1. 첫 돌입 | 창고형 전투 구역 | 8 |
| 2. 측면 공격 | 칸막이와 엄폐물이 있는 구역 | 12 |
| 3. 마지막 밤 | 전체 구역 | 59 |

앞의 두 스테이지는 보유한 바닥·벽 타일로 새로 배치했다. 벽 위치와 적 수가 달라 점점 복잡해진다. 마지막 스테이지는 기존 네 구역을 모두 사용한다. 현재 구역의 적을 정리하면 다음 계단을 이용할 수 있고, 다른 구역을 거쳐 돌아와도 처치 상태는 유지된다. 순찰 경로는 원작의 시작 위치를 기준으로 지정했다.

## 화면과 소리

배경과 스프라이트는 GameCraft의 분홍·청록 네온 리소스로 구성했다. 계단, 수조, 차량과 개는 같은 팔레트에 맞춰 그렸다. 배경음과 발사·피격·클리어 효과음을 재생하며, 전체 소리는 낮은 볼륨으로 설정했다.
