# 기말과제
- 성명: 전승효
- 게임이름: Shooter Lounge

## 실행
- Visual Studio에서 `src/gamename/gamename.slnx`를 열고 실행한다.
- 시작 화면에서 Enter를 누르거나 `게임 시작`을 클릭한다.
- WASD로 이동하고 마우스 왼쪽 버튼으로 발사한다. R은 현재 스테이지 재시작이다.
- 스테이지를 차례로 진행한다. 각 스테이지의 적을 모두 처치하면 `클리어!`가 표시된다. 시작 지점으로 돌아간 뒤 Enter를 누르면 다음 스테이지로 넘어간다.
- 적은 플레이어를 발견한 뒤 잠시 조준한다. 머리 위에 `!`가 뜰 때 피하거나 먼저 공격할 수 있다.
- 마지막 스테이지까지 마치면 게임 클리어 화면이 나온다. Enter, R 또는 버튼을 눌러 시작 화면으로 돌아간다.
- 배경음과 발사·피격·클리어 효과음이 재생된다.

리소스와 소리 출처는 `resource/resource_list.md`에 정리했다.
